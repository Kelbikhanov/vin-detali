# VINDetali Bot — форма поиска автозапчастей

Next.js 15 + React + TypeScript + Tailwind CSS. Архитектура организована по FSD.

## Запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env.local` и укажите свой ключ DeepSeek:

```env
DEEPSEEK_API_KEY=your_real_key
DEEPSEEK_MODEL=deepseek-chat
```

Затем запустите проект:

```bash
npm run dev
```

Откройте `http://localhost:3000`.

## Как работает поиск

1. Пользователь вводит VIN или выбирает марку, модель и год вручную.
2. Форма отправляет данные на внутренний маршрут Next.js `POST /api/parts/search`.
3. Серверный маршрут обращается к DeepSeek и возвращает нормализованный JSON с результатом.
4. API-ключ читается только из `process.env.DEEPSEEK_API_KEY` на сервере и не передаётся браузеру.

## Важно про реальные предложения

Подключённый DeepSeek Chat API сам по себе не гарантирует поиск по актуальным каталогам магазинов. Маршрут специально инструктирует модель не выдумывать товары, цены, наличие и ссылки; если предложения не подтверждены, список может быть пустым. Чтобы получать реальные карточки товаров с актуальными ценами и прямыми ссылками, следующим этапом нужно подключить отдельный источник поиска/каталоги продавцов и проверять совместимость.

## Безопасность перед публичным запуском

- Не добавляйте ключ в переменные с префиксом `NEXT_PUBLIC_`.
- Не коммитьте `.env.local` в Git.
- Ограничьте расходы и лимиты в кабинете DeepSeek.
- Перед публичным запуском добавьте ограничение частоты запросов (rate limiting), защиту от автоматизированного злоупотребления и, при необходимости, авторизацию.
