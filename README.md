# VINDetali Bot — форма поиска автозапчастей

Next.js 15 + React + TypeScript + Tailwind CSS, проект организован по FSD.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Текущее поведение формы

- Пользователь вводит VIN без отдельного шага «Определить».
- VIN проверяется локально по формату: 17 латинских букв/цифр, без I, O и Q. Внешние VIN API не вызываются.
- Поле «Какая деталь нужна?» становится доступным, когда введён корректный VIN.
- Под VIN находится текст «или можете ввести данные вручную»; подчёркнутая часть открывает/скрывает блок выбора марки, модели, года и двигателя.
- При ручном вводе поле поиска запчасти становится доступным после выбора марки, модели и года.
- Кнопка «Найти запчасть» проверяет заполнение формы и показывает демо-сообщение. Запрос к DeepSeek пока не отправляется.
